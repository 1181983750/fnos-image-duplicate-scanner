# 图片重复扫描

一个给飞牛 NAS 用的图片整理小工具。

它适合这种场景：

- 相册、网盘同步目录里越堆越多
- 同一张图被转发、备份、搬运了很多次
- 想先看预览，再决定删哪些
- 想顺手把 JPG / PNG 转成更省空间的 JXL

## 它能做什么

- 找出一模一样的重复图片
- 支持 `jpg`、`jpeg`、`png`、`webp`、`jxl`
- 扫描后按组展示，方便一眼看出哪些重复了
- 可以放大预览，再勾选要删除的文件
- 可以一键优先选中“较小、较像副本”的文件
- 可以把 JPG / PNG 转成 JXL
- 可以把别的目录里的图片导入进来并转成 JXL

## 下载

发布好的安装包会放在这里：

[GitHub Releases](https://github.com/1181983750/fnos-image-duplicate-scanner/releases)

下载后缀为 `.fpk` 的文件即可。

## 怎么安装

1. 打开飞牛的「应用中心」
2. 进入「手动安装」
3. 选择下载好的 `.fpk` 文件
4. 按提示完成安装

## 第一次打开前先做这一步

这个应用需要你先告诉它“哪些文件夹可以看”。

安装完成后：

1. 打开飞牛里的这个应用设置
2. 找到「授权目录」
3. 把你要扫描的图片目录加进去

比如：

```text
/vol1/1000/图片库
```

不授权的话，应用不会去读你的目录。

## 怎么用

### 1. 扫描重复图片

1. 打开应用
2. 在“扫描目录列表”里填你刚授权过的完整路径
3. 点「开始扫描」
4. 等待结果出来

如果你有多个目录，可以一行写一个。

### 2. 预览并删除

扫描完成后：

- 点缩略图可以看大图
- 勾选想删的文件
- 点「删除已选」

如果你不想一个个选，也可以点「一键选择小文件」，先自动帮你挑一批更像副本的文件。

### 3. 转成 JXL

勾上“转换 JPG/PNG 到 JXL”后再扫描，应用会在原图旁边生成 `.jxl` 文件。

说明：

- 原来的 JPG / PNG 不会自动删除
- 只是额外生成一份 JXL
- 你确认没问题后，可以自己决定要不要删原图

### 4. 导入图片

你也可以在“导入源文件”里填一个已经授权过的目录，或者某一张图片的完整路径。

导入时会先检查是不是已经有重复内容，避免重复塞进去。

## 使用提醒

- 删除文件是真删，不能撤销，删之前先看清楚
- 第一次启动会比平时慢一点
  因为系统要先帮应用准备运行环境
- 第一次启动时飞牛需要联网
- 图片很多时，扫描需要一点时间，属于正常现象

## 常见问题

### 为什么提示没有权限

大多数情况是因为还没在飞牛里加「授权目录」。

先去应用设置里把要扫描的目录加进去，再回来填完整路径。

### 为什么第一次打开比较慢

第一次启动时，应用会自动做一些初始化准备，所以会慢一点。后面就会正常很多。

### 我删掉的是原图吗

应用只会删除你亲手勾选并确认删除的那些文件，不会偷偷删别的。

### 支持哪些飞牛版本

建议在 `fnOS 1.1.8` 及以上版本使用。
